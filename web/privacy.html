개인정보처리방침

The World That Day(이하 "이 서비스")가 어떤 정보를 받고 어떻게 쓰는지 설명합니다.

운영자: The World That Day 운영자

받는 정보

이 서비스는 입력한 생년월일(날짜)과 태어난 장소를 받습니다. 계정, 이름, 연락처는 받지 않습니다. 지금 화면은 날짜만 서버로 보내며, 장소는 장소 입력이 생긴 뒤부터 받습니다.

정보를 쓰는 법과 공유

  • 받은 정보는 그날의 자료를 찾는 데만 씁니다.
  • 이 서비스의 서버는 날짜와 사건 이름으로 외부 출처에 자료를 요청합니다. 지금은 한국어 위키백과, Wikidata, Wikimedia Commons(날짜별 사진 분류)이고, YouTube Data API가 더해질 예정입니다. 장소를 해석하는 출처가 생기면 이 방침에 더합니다.
  • 외부 출처에는 누구의 생년월일인지 보내지 않습니다.
  • 날짜별 결과(위키백과 문단 등)는 서버에 캐시하지만, 요청한 사람의 정보(IP 주소 등)는 저장하지 않습니다.
  • 서버 작업 기록(로그)에 날짜와 관련된 문서 제목이 남을 수 있지만, 생년월일과 장소를 함께 남기지 않습니다.
  • 결과 화면 주소에는 생년월일과 장소를 넣지 않습니다.

다른 곳의 콘텐츠와 광고

결과 화면의 사진과 영상은 원 출처 서버(Wikimedia Commons 등)에서 브라우저가 직접 받아 옵니다. 이때 그 서버는 접속 정보(IP 주소 등)를 받습니다. YouTube 영상은 YouTube 플레이어(개인정보 보호 강화 모드)를 페이지에 넣어 보여 주며, YouTube가 플레이어 안에 광고를 낼 수 있습니다.

YouTube API 서비스

이 서비스는 YouTube API 서비스를 사용합니다. 이 서비스를 이용하면 YouTube 이용약관에 동의하게 됩니다. Google의 개인정보 처리는 Google 개인정보처리방침에서 볼 수 있습니다.

쿠키와 기기 저장

이 서비스는 쿠키나 브라우저 저장소를 쓰지 않습니다. 다만 YouTube 플레이어와 YouTube IFrame API 스크립트는 기기에 정보를 저장하거나 읽을 수 있으며, 개인정보 보호 강화 모드에서도 그럴 수 있습니다.

문의
