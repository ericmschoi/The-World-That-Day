# The World That Day — 제품 정의서

이 문서는 제품 요구사항의 원천이다. planner는 이 문서로 로드맵과 계획서를 만든다. 이 문서는 PM만 수정한다.

## 1. 한 줄 정의

생년월일과 태어난 장소를 입력하면, 그날 그곳의 대한민국 풍경과 그날 세계에서 일어난 일을 사진과 짧은 영상으로 보여주는 서비스.

## 2. 사용자와 목표 감정

- 주 사용자: 대한민국에서 태어나 자란 사람. 대부분 모바일로 들어온다.
- 목표 감정: "내가 태어난 날 우리 동네가 이랬구나" 하는 뭉클함과 신기함. 정보 나열이 아니라 한 편의 이야기처럼 느껴져야 한다.
- 성공 장면: 사용자가 결과를 끝까지 넘겨보고, 부모님이나 친구에게 보여주고 싶어진다.

## 3. 입력

| 항목 | 필수 | 예시 | 규칙 |
|---|---|---|---|
| 생년월일 | 필수 | 1988-09-17 | 미래 날짜, 존재하지 않는 날짜(2월 30일 등)는 거부. 지원 시작 연도는 M0 리서치 결과를 보고 PM이 정한다 (초안: 1950년 이후) |
| 태어난 장소 | 필수 | 서울 / 망원동 / 서울대학교병원 | 자유 입력 |
| 출생 시각 | 선택 | 15:20 | MVP에서는 오프닝 문구에만 쓰고 기능에는 쓰지 않는다 |

## 4. 장소 해석

입력한 장소를 세 유형으로 나눈다. PM 요구사항의 "넓은 지역"과 "구체적 장소" 사이에 "동네"를 둔다. 사용자가 가장 감동하는 지점이 자기 동네이기 때문이다.

| 유형 | 예 | 보여줄 것 |
|---|---|---|
| 광역 `REGION` | 서울, 부산, 경기도, 강남구, 수원시 | 그 지역 사람이면 누구나 아는 대표 명소 5~8곳 |
| 동네 `NEIGHBORHOOD` | 망원동, 해운대구 우동, 광주 서구 풍암동 | 동네 중심의 그때/지금 항공·위성 사진, 동네 곳곳, 그 도시의 대표 명소 일부 |
| 장소 `SPOT` | 서울대학교병원, 병원 이름, 주소 | 그 지점의 그때/지금 항공·위성 사진, 로드뷰, 반경 안의 동네 곳곳, 그 도시의 대표 명소 일부 |

규칙:
- 후보가 여러 개면(예: "중앙병원") 후보 목록을 보여주고 사용자가 고른다. 시스템이 추측해서 하나를 고르지 않는다.
- 문을 닫았거나 이름이 바뀐 병원처럼 찾지 못하는 장소는 동 단위로 다시 입력하도록 안내한다. 지도에서 직접 위치를 고르는 기능을 넣을지는 M2 계획 때 PM이 정한다.
- 대한민국 밖 장소는 MVP에서 지원하지 않고 안내 문구를 보여준다.

## 5. 결과 화면 — 이야기 순서

1. **오프닝**: "1988년 9월 17일 토요일, 서울". 요일을 계산해서 보여준다.
2. **그날의 동네** (`NEIGHBORHOOD`, `SPOT`): 출생 연도에 가장 가까운 항공사진과 현재 위성사진을 비교하는 슬라이더, 로드뷰나 거리 사진, 동네 곳곳 3~6장.
3. **그 도시의 풍경**: 대표 명소마다 출생 연도에 가장 가까운 기록 사진이나 영상. 그때 아직 없던 명소는 빼고, 지금은 사라진 명소는 넣을 수 있다.
4. **그날의 세계**: 정확히 같은 날짜(연·월·일)에 세계와 국내에서 일어난 사건을 사진이나 짧은 영상과 함께.
5. **마무리**: 이 결과에 쓰인 전체 출처 목록, 다른 날짜나 장소로 다시 해보기.

## 6. 미디어 원칙 (가장 중요한 제품 규칙)

### 6.1 정직한 날짜 표기

- 모든 사진과 영상에 실제 촬영 시점과 정밀도를 표시한다: `같은 날` / `같은 달` / `같은 해` / `±N년` / `현재 모습` / `촬영 시점 미상`(촬영 시점을 알 수 없을 때, 배지 없이 표시).
- 그날 찍지 않은 사진을 그날 사진처럼 보이게 하는 문구나 편집을 하지 않는다. 예: "1987년 촬영", "지금의 모습".
- 고르는 순서: 같은 날 → 같은 달 → 같은 해 → 가장 가까운 연도(초안: 최대 ±5년, M0 결과로 조정) → 현재 모습.
- AI가 생성하거나 합성한 이미지를 실제 기록처럼 쓰지 않는다.

### 6.2 라이선스

PM 결정(2026-10-11, 비상업 목적): 사진과 영상은 링크로 처리하지 않고 결과 화면에서 바로 보여 주고 재생한다.

- 라이선스가 확인되지 않은 자료도 화면에 직접 보여 줄 수 있다. 이때 `license` 는 비워 두고 화면에는 "라이선스 확인 안 됨"으로 표시한다.
- 영상은 화면에 보이면 음소거로 자동 재생하고, 사용자가 누르면 소리를 낸다(브라우저 자동 재생 정책).
- 미디어 파일은 우리 서버나 저장소에 복사·재배포하지 않는다. 원 출처 주소나 원 제공자의 공식 플레이어(임베드)로만 보여 준다. 예외는 PM이 받은 큐레이션 사본뿐이다.
- 고르는 순서: 자유 라이선스(Commons, 공공누리 1유형) → 업로더가 임베드를 허용한 공식 채널 영상(예: YouTube 공식 채널) → 그 밖의 출처 직접 표시.
- 원 출처가 핫링크나 임베드를 기술적으로 막아 화면에 띄울 수 없는 자료는 쓰지 않는다.
- 권리자가 요청하면 바로 내릴 수 있게 출처별 차단 설정을 둔다. 공개 배포를 정할 때 이 결정을 다시 본다.
- 모든 미디어 레코드는 아래 필드를 가진다. 출처(`source_name`, `source_url`, `attribution`)가 비어 있으면 화면에 보여 주지 않는다. 촬영 시점을 모르면 보여 주되 "촬영 시점 미상"으로 표시하고, 그날 찍은 것처럼 보이게 하지 않는다(PM 결정, 2026-10-11):

| 필드 | 설명 |
|---|---|
| `id` | 고유 ID |
| `type` | `photo` / `video` / `aerial` / `satellite` / `streetview` |
| `url`, `thumbnail_url` | 미디어 주소 |
| `source_name`, `source_url` | 제공 기관과 원문 페이지 |
| `license` | 예: `KOGL-1`, `CC BY-SA 4.0`, `PD`, `provider-terms`. 확인되지 않으면 비움 |
| `attribution` | 화면에 표시할 출처 문구 |
| `display_mode` | 화면에서 보여 주는 방식(이미지 직접 표시, 영상 파일 재생, 공식 플레이어 임베드 등). 값 목록은 M3a3 공용 미디어 형식에서 정한다 |
| `captured_at` | 촬영 시점 (모르는 부분은 비움) |
| `date_precision` | `day` / `month` / `year` / `approx` / `current`. 촬영 시점을 모르면 비움(null) → 화면에는 "촬영 시점 미상" |
| `lat`, `lng` 또는 `place_ref` | 위치 |
| `retrieved_at` | 가져온 시점 |

- 지도와 로드뷰 제공자의 약관(저장·캐싱 금지, 로고와 저작권 표시 등)은 M0 리서치 문서를 따른다.
- 통신사·언론사 사진(연합뉴스, AP, 게티이미지 등)은 직접 가져다 쓰지 않는다(핫링크 포함). 제공사가 공식 임베드 기능을 운영하면 그 방식으로만 쓴다.
- 공공누리는 유형마다 조건이 다르다(1유형만 상업 이용과 변경이 자유롭고, 나머지는 상업 이용 금지나 변경 금지 조건이 붙는다). 그래서 서비스를 상업화할지가 쓸 수 있는 자료 범위를 바꾼다. → PM 결정 사항.

### 6.3 사건의 톤

- 그날의 사건 중에는 참사, 전쟁, 테러 같은 비극이 있을 수 있다. 사건마다 `tone: normal | tragic` 을 두고, `tragic` 은 생일 축하 분위기와 분리해서 차분하게 보여준다. 잔혹한 이미지는 쓰지 않는다.
- 사건은 사실만 적고 특정 정치적 해석을 붙이지 않는다.

## 7. 데이터 출처 후보 (전부 미검증 — M0에서 확인)

| 영역 | 후보 | M0에서 확인할 것 |
|---|---|---|
| 장소 검색·좌표 | 카카오 로컬 API, 네이버 지도(NCP) Geocoding, Google Places / Geocoding | 병원·동 이름 검색 정확도, 장소 카테고리, 쿼터, 약관 |
| 과거 항공사진 | 국토지리정보원 국토정보플랫폼, 브이월드(공간정보 오픈플랫폼) | 좌표로 연도별 항공사진을 받을 수 있는지(API·타일·다운로드), 연도 커버리지, 이용 조건 |
| 현재 위성·로드뷰 | 카카오맵 로드뷰, 네이버 거리뷰, Google Street View / Maps Static | 웹 임베드 방법, 과거 시점 제공 여부, 캐싱 금지 등 약관 |
| 기록 사진·영상 | 국가기록원, 서울역사아카이브, e영상역사관(KTV·대한뉴스), 공공데이터포털, 한국관광공사 TourAPI | 검색 API 유무, 날짜·장소 메타데이터 수준, 공공누리 유형, 영상 임베드 가능 여부 |
| 그날의 사건 | Wikimedia "On this day" API, Wikidata, 위키백과 날짜 문서, Wikimedia Commons | 연·월·일까지 정확한지, 한국어 데이터 양, 이미지 라이선스 메타데이터 |
| 국내 사건 보강 | 국가기록원 기록물, 대한뉴스 회차 목록 | 날짜별 조회 가능 여부 |

현실적인 기대치: 특정 동네를 "그날" 찍은 사진은 대부분 없다. 동네 섹션의 핵심은 출생 연도 근처의 항공사진과 지금 모습의 비교가 될 가능성이 높다. M0는 이 가정을 확인하거나 뒤집는 단계다.

## 8. 비기능 요구사항

- 모바일 우선, 한국어 UI.
- 오프닝은 3초 안에, 전체 결과는 10초 안에(목표). 늦게 오는 섹션은 나중에 채운다.
- 외부 출처 하나가 실패해도 나머지 섹션은 정상으로 보여준다.
- API 키는 서버에만 둔다. 프론트엔드는 우리 백엔드만 호출한다. 지도 SDK처럼 약관상 브라우저 키가 꼭 필요한 경우만 예외로 하고, 도메인 제한을 건다.
- 약관이 허용하는 범위에서 외부 응답을 캐시해 쿼터를 아낀다.
- 개인정보: 회원가입 없음. 생년월일과 장소 입력값을 사람과 연결해서 저장하지 않는다. 로그에 생년월일과 장소를 함께 남기지 않는다.
- 테스트는 외부 API를 실제로 호출하지 않는다.

## 9. 범위 밖 (MVP)

로그인, 결제, 해외 장소, 출생 시각 기반 기능(사주, 별자리 등), AI 생성 이미지, 공유 카드와 SNS 공유, 다국어.

- 그날의 날씨 (후보: 기상청 기상자료개방포털 과거 관측자료)
- 공유용 카드 이미지와 링크
- 그해의 노래·영화 (저작권 문제가 커서 제목과 링크만 가능할 것)

## 12. 데모 입력과 MVP 완료 조건

데모와 테스트에는 아래 입력만 쓴다. 실제 사람의 생년월일은 쓰지 않는다.

| 입력 | 확인할 것 |
|---|---|
| 1988-09-17 + "서울" | `REGION`. 대표 명소, 그날의 사건(서울 올림픽 개막) |
| 2002-06-22 + "광주 서구 풍암동" | `NEIGHBORHOOD`. 동네 항공사진 그때/지금, 그날의 사건 |
| 1995-03-15 + "서울대학교병원" | `SPOT`. 지점 항공사진, 로드뷰, 동네 곳곳 |

완료 조건:
- 세 입력 모두 오프닝부터 마무리까지 결과가 나온다.
- 화면의 모든 미디어에 출처, 라이선스, 촬영 시점과 정밀도가 표시된다.
- 외부 출처 하나를 끊어도 화면이 깨지지 않는다.
