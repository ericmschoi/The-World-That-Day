# 대한뉴스 영상 자동 연결 (M3a5b)

> 브랜치: `feat/daehan-news-video` · 작성: planner · 상태: **PM 승인 (2026-10-12)** (M3a5의 이전 T2를 나눠 새로 생김, 로드맵 D1 (a)) · 2026-10-12: N3 결과와 R-N5·R-N7·R-N8(리서치 3.5절·7절, 6bf0267) 반영
> 기준: `docs/research/video-sources.md` 3.3절(V5 카드), 3.5절(N3·Y2·Y4 결과, 제목 변형, [177]), 4절 V5 표, 5절 V5 표, 6.3절, 7절 V5 추천·R-N1~R-N8·R-Y2, 8절 위험 18~24, 10.1절 8·10·11·12·13번, `docs/plans/m3a4-event-video.md`, `docs/plans/m3a5-official-channel-video.md`, `CLAUDE.md` 7절 1·2·5·6·7항
> 선행: M3a5 머지 + T0(PM: 공공데이터포털 활용신청, N1·N2, CSV 내려받기 N-B1, Y4에 제1611호 ID) + T0b(data-researcher가 색인 경로 N-a를 "확인됨"으로) + T1(content-curator 색인). **지금 상태: 제목 대조(N-e·N-f의 제목 형식)는 N3로 확인됐고, 색인(N-a)은 "부분 확인"이라 막혀 있다(PM 작업 대기).**

## 목표

1. 사건 날짜 d가 **1953-06-23 ~ 1994-12-31** 이면, `data/` 의 대한뉴스 꼭지 색인에서 회차 날짜가 **d ~ d+7** 이고 **꼭지 제목에 사건어가 있는** 꼭지를 찾는다(10.1절 10·12번).
2. M3a5가 이미 받은 KTV 아카이브 검색 결과에서 제목 맨 앞 "대한뉴스 제 N호"의 호수가 그 꼭지와 같은 영상을 고른다(N-e, 추가 요청 0). 없으면 그 꼭지로 채널 한정 검색을 1회 더 한다(N-f).
3. 고른 영상에 회차 날짜를 `approx` 로 붙이고, 캡션 출처에 **"대한뉴스(정부 제작 뉴스영화)"** 를 적는다(10.1절 13번).
4. 재생은 **KTV 아카이브 YouTube 임베드로만** 한다. e영상역사관 플레이어·페이지 iframe은 쓰지 않는다.

## 범위 밖

- e영상역사관 플레이어·페이지 iframe(공식 임베드 없음), e영상역사관 정보 조회 API(N-c), 목록 페이지 긁기
- 서버가 odcloud API로 색인을 받는 방식(N-b) — 10.1절 11번 (a)로 쓰지 않음. N1·N2는 값 형식 확인용
- 색인에서 꼭지를 찾았지만 YouTube 영상이 없을 때 링크만 보여 주기(`CLAUDE.md` 7절 1항 — 레코드를 만들지 않음)
- e영상역사관 꼭지 내용 요약 문단 옮기기(위험 24)
- **컬러 복원 재업로드**(「[📺컬러 복원] … [대한뉴스 698호] 📽️1968년 11월 2일 방영」) — M3a5가 후보에서 뺀다(R-N5, "M3a5에서는 쓰지 않음" 추천). 보조 정규식 `\[대한뉴스\s*(?:제\s*)?(\d+)\s*호\]` 와 "컬러 복원" 캡션은 후속 작업 후보

## 데이터 형식 (`data/daehan-news/`, content-curator)

`segments.csv` — UTF-8, 첫 줄 머리글:

```
issue_no,issue_date,segment_title,duration_seconds,source_url
1715,1988-09-17,서울 올림픽 개막,576,https://www.ehistory.go.kr/view/movie?...
736,1969-07-26,사람이 달에 내리다-아폴로 11호 제1신-,298,https://www.ehistory.go.kr/view/movie?...
1611,1986-09-20,아시안 게임 개막,555,https://www.ehistory.go.kr/view/movie?...
```

- `issue_no` 정수(원본 `호수` 가 "제1715호" 형식이면 숫자만), `issue_date` `YYYY-MM-DD`(원본 `제작일`), `segment_title` 원문 그대로(NFC), `duration_seconds` 정수 또는 빈 값(원본 `재생시간(초)`), `source_url` 원본 `링크주소`(`http(s)`).
- **방영본만** 넣는다. 방영본을 가르는 열(`메뉴코드`·`대분류`·`중분류`)과 값은 T0의 N1·N-B1 결과로 정해 `README.md` 에 적는다.
- 1953-06-23 ~ 1994-12-31 밖의 행은 넣지 않는다.
- `README.md`: 데이터셋 이름·주소, 원본 파일 이름, 기준일(20251031), 이용허락범위, 받은 날짜, 방영본 거름 규칙, 원본 행 수와 색인 행 수, 바꾼 것(열 이름, 호수 숫자화, NFC).

## 규칙

| 규칙 | 내용 |
|---|---|
| 수록 기간 | d가 1953-06-23 ~ 1994-12-31 밖이면 요청 0(10.1절 10번 (a), R-N4) |
| 매칭 창 | `issue_date` ∈ [d, d+7] (설정 `daehan-news.match-window-days` 7). 사건 앞 회차(준비·예행연습·카운트다운 보도)는 보지 않는다(10.1절 12번 (a), R-N1) |
| 꼭지 단위 | 꼭지 제목에 사건어가 있어야 한다(M3a4 사건어 대조 — 한국어 핵심어, 띄어쓰기 무시, 숫자 핵심어 필수) (R-N2) |
| N-e 제목 대조 (R-N5) | M3a5의 Y-a 결과 중 제목(NFC)이 정규식 `^\s*대한뉴스\s*제\s*(\d+)\s*호\s*-` 에 맞고 잡힌 호수가 위 꼭지의 `issue_no` 와 같은 영상. 맨 앞만 보므로 꼭지 제목 안의 "제1신"·"제 9회"는 호수가 아니다. 공백·"-" 앞뒤 공백은 고정하지 않는다(3.5절에서 「대한뉴스 제 23호 - …」 확인). 호수 검색은 정확 일치가 아니므로 결과 제목의 호수를 반드시 대조한다 |
| N-f 보조 검색 | N-e로 못 찾았고 색인에 맞는 꼭지가 있을 때만, 사건마다 최대 1회: KTV 아카이브 한정 `q="대한뉴스 제 {호수}호 {꼭지 제목}"`. 검색 버킷이 없으면 건너뛴다(캐시하지 않음). 결과에도 N-e 대조를 그대로 적용 |
| 확인 | 고른 영상은 M3a5의 `videos.list` 확인·버림 규칙(임베드·공개·KR·연령·10분·채널 ID·컬러 복원) 그대로. N-f로 얻은 ID는 같은 날짜의 묶음에 더해 `videos.list` 1회 |
| 같은 꼭지 여러 ID (R-N7) | (호수, 꼭지 제목)이 같은 영상이 둘 이상이면 확인을 통과한 것 중 `publishedAt` 이 가장 이른 하나만 남긴다 |
| 설명의 "제작일" (R-N8) | 설명 첫 줄의 "제작일: YYYY-MM-DD"(3.5절 Y4: 표본 2/2)가 있으면 색인 `issue_date` 와 같은지 본다. **다르면 회차 날짜를 붙이지 않는다.** 날짜의 원천은 색인이고 설명은 대조용이다. 설명에 "제작일"이 없으면 대조를 건너뛴다(모든 영상에 있는지는 모름) |
| 길이 대조 (R-N6) | YouTube 길이와 색인 `duration_seconds` 의 비가 2배를 넘으면(설정 `daehan-news.max-duration-ratio` 2.0) 다른 편집본으로 보고 회차 날짜를 붙이지 않는다. 색인 길이가 비면 대조하지 않는다. 표본: 9분 33초 대 9분 36초, 4분 59초 대 4분 58초(3.5절) |
| 날짜·점수 | 회차 날짜를 `explicit_dates` 로 넘긴다 → M3a4 날짜 점수(같은 날 +40, 같은 달 +20, 같은 해 +10). `captured_at` = 회차 날짜, `date_precision` `approx` → R8로 `captured_at` 은 연도("1988"), 화면은 "같은 해 무렵", "1988년 무렵 촬영(추정)"(R-N3). `publishedAt`·`recordingDate` 는 쓰지 않는다 |
| 레코드 값 (4절 V5) | YouTube 레코드와 같고 다른 것만: `selection.basis` `daehan_news`, `attribution` "대한뉴스 제{호수}호 ({YYYY}년 {M}월 {D}일 자) · 대한뉴스(정부 제작 뉴스영화) · {채널 이름} · YouTube", `description` 꼭지 제목. 같은 영상이 M3a5 결과로도 나오면 레코드는 하나(M3a4 "같은 영상" 규칙, `daehan_news` 우선) |
| 날짜를 붙이지 못함 | 길이·"제작일" 대조 실패면 회차 날짜를 붙이지 않고 `attribution` 에도 날짜를 넣지 않는다. 점수는 보통 50이라 버려진다 |
| 색인 파일 | `app.data-dir`/`daehan-news/segments.csv` 를 시작할 때 읽는다. 없으면 WARN 1줄 후 이 어댑터를 끈다. 형식이 틀리면 시작 실패(M3a2 큐레이션과 같은 방식) |
| 키 | `YOUTUBE_API_KEY` 가 없으면 이 어댑터도 끈다(재생 경로가 YouTube뿐, 위험 18) |
| `tragic` | 요청 0 |

## API / 데이터 변경

- 응답 형식 그대로. `video_embed` 레코드의 `selection.basis` 에 `daehan_news` 가 나오고 `attribution` 이 위 형식이다. 예: `"attribution": "대한뉴스 제1715호 (1988년 9월 17일 자) · 대한뉴스(정부 제작 뉴스영화) · KTV 아카이브 · YouTube"`, `"captured_at": "1988"`, `"date_precision": "approx"`, `"date_relation": {"kind": "approximate", "years": 0}`.
- 새 데이터 파일 `data/daehan-news/segments.csv`, `README.md`. 설정 `daehan-news.*`.
- DB 변경 없음.
