# 영상·공식 임베드 출처 리서치 (M3 영상 선행)

> 브랜치: `docs/m3-video-sources` · 작성: planner · 상태: PM 승인 (M3-P6, 2026-10-11) · 2026-10-11 M3-P9 (b) 반영 개정
> 기준: PM 미디어 결정 2026-10-11(사진·영상은 바로 보이고 바로 재생, 라이선스 미확인도 직접 표시, 비상업), 안전장치 1~6(PM 확인, 3은 개정판: 통신사·언론사는 공식 임베드로만), **M3-P9 (b): 사용자가 넣은 아무 날짜에서나 사건 영상과 제공사 공식 임베드를 자동으로 찾는다**, `CLAUDE.md` 7절 2항(구현에는 "확인됨" 출처만)·4항(키는 PM이 발급, 에이전트는 키를 쓰지 않음), `docs/plans/m0-source-research.md`(확신도 기준)
> 위치: 문서만 바꾸는 기능. 계획 승인 직후 다른 M3 기능과 **병렬**. 결과가 M3a4·M3a5·M3a6(서버)와 M3b3(웹)의 선행 조건이다. 테스트 단계 없음.

## 목표

1. **임의 날짜에서 자동으로** 그날 사건의 영상과 제공사 공식 임베드를 찾을 수 있는 경로(검색 방법, 필요한 키, 쿼터, 약관)를 출처마다 확인한다.
2. 각 경로로 찾은 결과를 화면에서 바로 재생·표시할 수 있는지(임베드 허용, 핫링크 가능 여부)를 확인한다.
3. 데모 날짜 3개와 **표본 날짜**(아래)로 경로마다 실제로 얼마나 찾히고 얼마나 맞는지 본다. 결과는 `docs/research/video-sources.md` 에 적는다.

표본 날짜 (실제 사람의 생년월일이 아니라 공개된 역사 사건 날짜와 경계값, `CLAUDE.md` 7절 6항): 데모 3개(1988-09-17, 2002-06-22, 1995-03-15) + 1950-06-25(지원 시작 연대, 비극) + 1969-07-20(세계 사건) + 1986-09-20(국내 행사) + 2000-02-29(윤일 경계) + 2014-04-16(국내 비극). PM이 바꿀 수 있다. 같은 표본을 M3a4~M3a6의 PM 품질 확인에 쓴다.

## 범위 밖

- 파일 내려받기, 우리 서버로 복사 (안전장치 1)
- 계정 가입, 로그인, 약관 동의, **키 발급·사용** — 키가 필요한 확인은 PM 확인 명령(`$ENV_VAR`)으로만 적는다
- 통신사·언론사 자료의 직접 표시·핫링크 경로 (공식 임베드만 조사)

## 조사 대상과 질문

| ID | 대상 | 확인할 것 |
|---|---|---|
| V1 | **Commons 동영상 자동 검색** (키 불필요) | 사건 → Commons 동영상으로 가는 경로: (a) 사건 QID의 Commons 범주(P373, sitelink), (b) Action API 검색(`list=search`/`generator=search`, `filetype:video`, 검색어), (c) 날짜 범주. 경로별 표본 날짜 결과 수와 맞는 비율(사람이 판정). 파일의 원본·변환본 주소, 길이, 포스터, 라이선스 필드, `<video>` 핫링크 가능 여부 |
| V2 | **YouTube 자동 검색** (키 필요) | YouTube Data API `search.list`·`videos.list`: 필요한 키 종류(서버 키), 호출당 쿼터 비용과 기본 일일 쿼터, `channelId` 로 공식 채널 한정 검색이 되는지(채널 여러 개면 호출 수), `status.embeddable` 로 임베드 허용 확인, 응답의 날짜 필드가 게시일뿐인지. **API 서비스 약관·개발자 정책**: 결과 캐시 허용 기간, 표시 조건, 비상업 여부. 키 없이 임베드 허용만 확인하는 방법(oEmbed 등)의 근거 |
| V3 | **공식 채널 목록** | KTV 국민방송, 국가기록원, e영상역사관 등 정부·공공기관 YouTube 채널의 공식 근거(기관 누리집 링크)와 채널 ID |
| V4 | **YouTube 임베드 약관** | iframe 조건, 음소거 자동 재생, 겹치기·가리기 금지, `youtube-nocookie.com`, IFrame Player API(`enablejsapi` + `postMessage`) 조건 |
| V5 | **e영상역사관·대한뉴스 날짜 검색** | 공공데이터포털 대한뉴스관 API·파일(키 `DATA_GO_KR_SERVICE_KEY`, M0 T4 A2·B1)로 날짜에 가까운 회차를 자동으로 찾는 방법, 회차·꼭지 페이지의 공식 플레이어 임베드(퍼가기) 가능 여부, 1958~1994년만 있다는 점 |
| V6 | **제공사 공식 이미지 임베드 검색** | **게티이미지**: 공식 임베드 운영 여부(2026년), 비상업 이용 조건, 임베드 코드 형식(로고·광고·추적), **자동 검색 경로**(검색 API의 키·약관, 결과에 "임베드 가능" 표시가 있는지), 캡션의 촬영일·작가. **AP·연합뉴스·로이터·AFP** 등의 공식 임베드와 검색 경로 유무 |
| V7 | **자동 검색 정확도 기준의 재료** | 경로마다 사건과 결과를 맞춰 볼 수 있는 메타데이터: 제목·설명의 날짜 표기, 촬영일 필드, 범주·태그, 사건 QID 연결. 엉뚱한 결과(이름만 같은 다른 사건, 기념 행사, 재현 영상) 예. `tragic` 사건 영상의 잔혹한 장면 위험 |

공통 질문: 날짜 정밀도(촬영·방송·게시 중 무엇인지, 6.1절 표기 매핑), 출처 표시에 필요한 값, 해상도별 대략 용량(모바일), 캐싱·저장 조항.

## 산출물 형식 (`docs/research/video-sources.md`)

M0 영역 문서 구성(요약 / 질문과 답 / 출처 카드와 항목별 확신도 / 미디어 레코드 필드 매핑 — `docs/plans/m3a3-event-media.md` 형식 / 데모·표본 날짜 판단 / PM 확인 명령 / 추천안 / 위험 / PM 결정 / 근거 링크)에 다음을 더한다.
- **자동 검색 경로 표**: 경로, 키(환경변수 이름 제안, 서버 전용), 쿼터·속도 제한, 요청 한 번당 비용, 캐시 허용, 확신도.

- **정확도 규칙 제안**: M3a4 계획서 "정확도 규칙"과 대조해 바꿀 점.

## 리스크와 확인할 것

1. **키가 필요한 경로는 PM 호출 전까지 "부분 확인"** — YouTube·게티 검색은 PM이 키를 발급하고 확인 명령을 실행해야 "확인됨"이 된다(`CLAUDE.md` 7절 4항). 그전에는 M3a5·M3a6을 시작할 수 없다.
2. **표본 날짜 일부는 영상이 없을 수 있다** — 정상 결과다(그 날짜는 사진만, M3-P9 결정).
3. **약관 해석은 법률 자문이 아니다.**

## PM이 정할 것

리서치 결과로 정한다(T5 보고서). 미리 알 수 있는 것: YouTube Data API 키(`YOUTUBE_API_KEY`, 서버 전용) 발급 여부, 게티 등 검색 키 발급 여부.
