# 공식 채널 영상 자동 검색: YouTube·대한뉴스 (M3a5)

> 브랜치: `feat/official-channel-video` · 작성: planner · 상태: PM 승인 (2026-10-11) (2026-10-11 M3-P9 (b)로 새로 생긴 기능) · **2026-10-11 갱신: 리서치 T1 결과로 국내 사건 영상의 주 경로가 됨, 촬영 시점 미상 표시 결정 반영**
> 기준: M3-P9 (b)(아무 날짜에서나 자동으로 찾는다), M3-P14(허용 공식 채널만, 결정), 안전장치 1~6(PM 확인), `CLAUDE.md` 7절 1항(촬영 시점을 모르면 "촬영 시점 미상"으로 표시하고 그날 것처럼 보이게 하지 않는다 — PM 결정 2026-10-11)·2·4·5항, `docs/plans/m3a4-event-video.md`(검색 틀·정확도 규칙), `docs/plans/m3a3-event-media.md`(형식), `docs/plans/m3-video-sources-research.md` V2~V5
> 선행: M3a4 머지 **그리고** 리서치에서 YouTube Data API·공식 채널 목록·임베드 약관이 "확인됨"(키가 필요하므로 **PM이 키를 발급하고 확인 명령을 실행한 뒤** data-researcher가 갱신). 대한뉴스(T2)는 V5가 "확인됨"일 때만.

## 이 기능의 무게가 커졌다 (2026-10-11, 리서치 T1)

리서치 T1은 국내(한국) 사건 날짜에서 Commons 동영상을 찾지 못했다. 데모 날짜 3개와 국내 표본 날짜는 모두 국내 사건이므로, **데모에서 사건 영상이 보일지는 사실상 이 기능(공식 YouTube 채널, 1958~1994년은 대한뉴스)에 달려 있다**. 그래서:

- PM의 YouTube Data API 키 발급과 확인 명령 실행(T0)을 리서치 머지 직후 가장 먼저 한다(로드맵 "PM 작업").
- 키가 늦어지면 M3 영상은 세계 사건의 Commons 영상만 남는다. 이 경우에도 화면은 정상(사진만)이다.
- 대한뉴스(T2, 조건부)는 1958~1994년 국내 사건(데모 1988-09-17, 표본 1986-09-20)의 보조 경로라 V5 결과를 특히 챙긴다.

## 목표

1. M3a4 검색 틀에 **YouTube 공식 채널 어댑터**를 붙인다: 사건마다 YouTube Data API로 검색하고, 허용 채널(공식 정부·공공기관 채널)의 임베드 허용 영상만 `video_embed`(`provider: youtube`)로 만든다.
2. 쿼터를 지킨다: 하루 사용량 상한을 넘으면 그날은 이 출처를 건너뛴다(사진·Commons 영상은 그대로).
3. (조건부) 1958~1994년 날짜는 **대한뉴스** 회차를 날짜로 찾아 공식 플레이어 임베드가 확인된 경우 `video_embed` 로 붙인다.

## 범위 밖

- 허용 채널 밖의 YouTube 영상(안전장치 4의 "그 밖" 단계 — 정확도·저작권 위험이 커 M3에서는 넣지 않는다, M3-P14 결정)
- 영상 내려받기·서버 경유 재생
- 웹 재생 (M3b3)

## 사용할 외부 출처 (리서치로 확정)

| 출처 | 확신도 (조건) | 쓰는 것 | 지킬 조건 |
|---|---|---|---|
| YouTube Data API (`search.list`, `videos.list`) | 리서치 V2에서 **확인됨**이어야 함 (PM 키 확인 뒤) | 검색, 채널, 제목·설명, `status.embeddable` | 키는 서버 전용 `YOUTUBE_API_KEY`(PM 발급, `.env`). 쿼터, API 서비스 약관의 캐시 기간·표시 조건(리서치 문서대로) |
| YouTube 임베드 플레이어 | V4 **확인됨** | `https://www.youtube-nocookie.com/embed/<ID>?autoplay=1&mute=1&playsinline=1&enablejsapi=1&rel=0` | 플레이어 가리기 금지 등(M3b3) |
| 대한뉴스(공공데이터포털 API) + e영상역사관 플레이어 | V5 **확인됨**일 때만 | 날짜에 가까운 회차, 공식 플레이어 주소 | 키 `DATA_GO_KR_SERVICE_KEY`(PM). 주간 발행일이라 `date_precision: approx`(#17 (a)) |

## 규칙

| 규칙 | 내용 |
|---|---|
| 검색어 | 사건 대표 링크 제목(한국어) + 사건 연도. 사건마다 `search.list` 1회(`type=video`, 임베드 가능 필터가 리서치로 확인되면 사용) |
| 채널 한정 | 결과 중 허용 채널 목록(설정값 `youtube.allowed-channels`, 리서치 V3의 채널 ID)에 있는 것만 남긴다. 리서치가 채널 한정 검색을 싸게 할 수 있다고 확인하면 그 방식으로 바꾼다 |
| 임베드 확인 | 남은 후보를 `videos.list` 1회로 묶어 `status.embeddable` 이 true인 것만 |
| 정확도 | M3a4 정확도 규칙(공식 출처 +20 포함), 기준선 미만은 버림 |
| 촬영 시점 | 제목·설명에 **명시된** 촬영·방송 날짜만. 게시일 `publishedAt` 은 쓰지 않는다. 명시가 없으면 `captured_at`·`date_precision` 은 `null` → `date_relation.kind = unknown`, 화면 "촬영 시점 미상"(그날 영상처럼 보이게 하지 않음, PM 결정 2026-10-11). 사건 날짜를 `captured_at` 으로 옮기지 않는다 |
| 쿼터 | 하루 사용량 상한(설정값 `youtube.daily-unit-budget`, 처음 8,000 — 기본 쿼터 10,000의 80%, 리서치 값으로 보정). 호출 전에 비용을 더해 보고 넘으면 호출하지 않는다(그 출처만 건너뜀, `partial` 은 바꾸지 않음 — 쿼터 소진은 오류가 아님). 카운터 초기화 시각은 리서치 값 |
| 캐시 | M3a4 결과 캐시를 쓰고, TTL은 API 서비스 약관이 허용하는 기간 이하(리서치 값) |
| 키 없음 | `YOUTUBE_API_KEY` 가 비면 이 어댑터를 끈다(요청 0, 시작 WARN 1줄, 값은 출력하지 않음) |
| `tragic` | M3a4와 같음(찾지 않음) |

## 테스트 방침

- YouTube·공공데이터포털 응답은 **공식 문서 필드 구조로 만든 합성 fixture**(#12 (a) — Google 응답은 녹화하지 않는다). fixture 옆 README에 근거 문서 URL.
- 테스트는 키를 쓰지 않는다. 테스트 설정은 가짜 키 문자열과 WireMock 주소.
- 실제 결과 품질은 PM 품질 확인(T4).

## 리스크와 확인할 것

1. **쿼터** — `search.list` 는 호출 비용이 크다(리서치로 확인). 사건 3개 × 하루 요청 수가 쿼터를 넘으면 그날은 YouTube 영상이 빠진다. 대응: 결과 캐시, 사건 3개 제한, 상한 80%, 쿼터 증설은 PM이 Google에 신청.
2. **엉뚱한 영상** — 공식 채널이라도 회고·기념 영상이 많다. M3a4 정확도 규칙과 PM 품질 확인.
3. **키 노출** — 서버 전용, 로그에 남기지 않는다.
4. **약관 변경·임베드 차단** — 결과 캐시 TTL을 약관 이하로, 차단 목록.
5. **저작권** — 공식 채널·공식 임베드라 낮지만 로드맵 리스크 4를 따른다.
6. **국내 영상의 유일한 주 경로** (리서치 T1) — Commons에 국내 날짜 영상이 없어, 키 발급이 늦어지거나 공식 채널 검색 결과가 적으면 데모 날짜에 영상이 하나도 없을 수 있다. 화면은 정상(사진만)이지만 PM 기대와 다를 수 있다. 대응: T0을 리서치 머지 직후로 당기고, 리서치 T2가 데모 날짜의 공식 채널 후보를 키 없이 볼 수 있는 범위(채널 페이지 등)로 미리 예시한다. 대한뉴스(T2)를 1958~1994년 보조 경로로 챙긴다.
7. **게시일만 있는 영상이 많다** — 공식 채널 영상은 제목·설명에 촬영일이 없는 경우가 많을 수 있다. 그런 영상은 "촬영 시점 미상"으로 보이고, 날짜 일치 점수가 없어 기준선을 넘기 어렵다. 결과가 너무 적으면 PM 품질 확인 뒤 점수 보정을 정한다.
