# 캐나다 전환: 기록 사진·영상과 공식 채널 — 출처 검증

> 작업: T4 (캐나다 전환 리서치) · 계획서: docs/plans/canada-research.md · 조사 일자: 2026-10-29 · 작성: data-researcher
> 이 문서의 약관 해석은 법률 자문이 아니다. 확신도 기준은 `docs/plans/m0-source-research.md` 의 "확신도 기준"을 따른다.
> 이 문서의 `[n]` 은 11절 번호다. 한국 리서치를 가리킬 때는 `docs/research/video-sources.md`(이하 V문서)와 `docs/research/archive-media.md`(이하 A문서)를 파일 이름으로 쓴다.
> 요청 방법: 공개 엔드포인트와 공개 웹 페이지만 키 없이 불렀다. 셸 요청의 User-Agent는 `TheWorldThatDay/0.1 (https://github.com/ericmschoi/The-World-That-Day)` 하나만 썼고(연락처는 저장소 주소, 이메일 없음), 같은 호스트에는 1초 이상 간격으로 직렬 요청했다. 약관 문서는 WebFetch(User-Agent 변경 불가, 기본값)로 읽었다. 가입, 로그인, 약관 동의, 키 사용은 하지 않았다. YouTube Data API는 부르지 않았고 6절 명령으로 남겼다.
> 자동 접근이 막힌 곳(캐나다 공영방송 CBC, 연방 도서관·기록보관소 LAC의 기록 페이지, 밴쿠버 시, 퀘벡 국립도서관·기록보관소 BAnQ, 캘거리 대학)은 우회하지 않았다. 그 사실을 "미확인"과 함께 적고, 6절에 PM이 브라우저로 확인할 항목(B번호)을 남겼다.
> 미디어 파일과 API 응답 원문은 저장소에 넣지 않았다. 문서에는 필드 이름, 개수, 대표 값만 적었다. 영상은 재생하지 않았다. YouTube 영상 페이지의 공개 HTML(업로드일, 임베드 가능, 시청 가능 국가)과 oEmbed 응답은 **연구용 단서**로만 읽었고, 서비스가 이 경로를 쓰라는 뜻이 아니다(V문서 3.2절과 같은 취급).
> 실제 사람의 생년월일은 쓰지 않았다. 날짜는 계획서 결정 1의 데모 날짜와 공개된 역사 사건 날짜뿐이다.

## 1. 요약

- **날짜나 장소로 검색할 수 있는 공개 API를 가진 캐나다 기록보관소는 하나도 확인하지 못했다.** LAC Collection Search는 문서화된 API가 없고 결과 목록 내려받기(HTML, CSV, XML, JSON)만 있으며, 스크립트 요청에는 보안 확인 화면(HTTP 403)이 나온다 [1][4][5]. 토론토 기록보관소 포털은 `robots.txt` 가 전체 금지(`Disallow: /`)이고 [29], 밴쿠버·BAnQ·캘거리 대학 사이트는 봇 차단이나 요청 제한이 걸려 있다 [37][40][41]. **그래서 기록 사진의 자동 경로는 이미 있는 Commons 어댑터(기록보관소가 Commons에 올린 사본)뿐이다** [31][32].
- **KTV 아카이브 채널의 후속은 "Radio-Canada Archives"(YouTube 채널 `UC-x9MHwagk0x1hGA5-TqkHA`)가 가장 가깝다.** 라디오 1936년, 텔레비전 1952년부터의 소장품이라고 채널이 소개하고, 방송사 누리집이 그 채널을 직접 링크한다 [19][23]. 다만 프랑스어이고, 표본 2건 중 1건이 **캐나다에서만 재생**된다(`availableCountries: ["CA"]`) [24][25]. 영어권 "CBC Archives" YouTube 채널은 추측한 이름 5개로 찾지 못했다(없다는 증명은 아님) [22].
- **데모 4개 중 3개(1976 몽레알, 1988 캘거리, 2010 밴쿠버 올림픽)는 "Olympic Games" 공식 채널(`UCTl3QQTvqHFjurroKxexy2Q`)의 공식 영화·하이라이트가 덮는다**(임베드 가능 확인, 업로드일은 2014~2015년이라 촬영일이 아님) [26]. 1980 테리 폭스 출발은 Radio-Canada Archives의 회고 몽타주(설명에 "1980년 4월 12일"이 적힘, 업로드 2025년) 1건을 찾았다 [25]. 모두 채널 ID와 임베드는 6절 명령이 끝나야 "확인됨"이 된다.
- **라이선스는 한국의 공공누리 같은 통일 표시가 없다.** Open Government Licence – Canada는 정보 라이선스이고 이미지에 적용되는지 문서에 적혀 있지 않다 [11]. 기록보관소마다 다르다: 토론토는 시가 저작권을 가진 기록은 "어떤 목적이든 허락이 필요 없다" [28], 몽레알 기록보관소는 CC BY-NC-SA 4.0(상업 금지) [34], BC·알버타는 허락이 필요하고 BC는 이미지 변경 금지 [38][39], NFB는 "개인적 사용만" 임베드 허용 [12].
- **제품 정의서/CLAUDE.md와 다른 점**: 6.2절 고르는 순서의 "공공누리 1유형"에 해당하는 캐나다 표시가 없고, 공식 YouTube 아카이브 채널은 프랑스어 방송사 쪽만 확인된다(9절). 통신사 예에 The Canadian Press를 넣을 필요가 있다(8절 위험 10, 결정 5와 연결).

## 4. 미디어 레코드 필드 매핑

제품 정의서 6.2절 필드 전부. 칸마다 `응답 필드명` / `고정값` / `계산` / `채울 수 없음 — 이유` 중 하나다. A는 Commons 경유 기록보관소 사진, B는 YouTube 공식 채널 영상, C는 몽레알 기록보관소 직접(큐레이션용), D는 NFB 임베드다. `display_mode` 값은 `data/schema/media.schema.json` 의 enum(`image`, `image_embed`, `video_file`, `video_embed`, `sdk`, `link_only`)이다.

| 필드 | A. Commons 사본 | B. YouTube 공식 채널 | C. 몽레알 기록보관소 | D. NFB 임베드 |
|---|---|---|---|---|
| `id` | 계산: Commons `pageid` 에서 어댑터가 만듦 | 계산: `yt:` + `id.videoId` | 계산: 기록의 문서 코드(`cote`) | 계산: `nfb:` + 영화 `slug` |
| `type` | 고정값: `photo` | 고정값: `video` | 고정값: `photo` | 고정값: `video` |
| `url` | `imageinfo.url` | 계산: 임베드 주소 `https://www.youtube-nocookie.com/embed/<videoId>` + 매개변수(V문서 V4 제안) | 기록 페이지의 디지털 객체 주소 (핫링크 가능 여부 미확인) | 계산: `https://www.nfb.ca/film/<slug>/embed/player/` |
| `thumbnail_url` | `imageinfo.thumburl` (`iiurlwidth`) | `snippet.thumbnails.*.url` | 미확인 (기록 페이지 구조 못 읽음) | JSON-LD `thumbnailUrl` |
| `source_name` | 고정값: "Wikimedia Commons" (원 기관은 `attribution`) | 계산: "YouTube · " + `snippet.channelTitle` | 고정값: "Archives de la Ville de Montréal" | 고정값: "National Film Board of Canada" |
| `source_url` | `imageinfo.descriptionurl` | 계산: `https://www.youtube.com/watch?v=<videoId>` | 기록 페이지 주소 | 영화 페이지 주소 (JSON-LD `url`) |
| `license` | `extmetadata.LicenseShortName` 원문 그대로 (표본: Public domain, CC BY 2.0, `Attribution`). 비어 있으면 null | 고정값: `provider-terms` | 고정값: `CC BY-NC-SA 4.0` (조건 페이지 [34]) | 고정값: `provider-terms` |

| `captured_at` | `extmetadata.DateTimeOriginal` 을 날짜로 읽되 **Flickr 사본 판별 필요**(아래 규칙) | 제목·설명의 명시 날짜만. `recordingDetails.recordingDate` 는 이 채널들에서 미확인 | 제목의 날짜 문자열(프랑스어)을 읽음 | 채울 수 없음 — 제작 연도만 있고 촬영일이 아님 |

날짜 규칙 제안 (V문서 7절 "정확도 규칙"과 같은 방식, 확정 아님):
1. Commons 사본: 파일의 `Credit`·`Source` 가 Flickr 주소이거나 `DateTimeOriginal` 이 사건 날짜보다 늦으면 `captured_at` 은 비우고 "촬영 시점 미상"으로 둔다(관찰: LAC·토론토 Flickr 사본).
2. YouTube: 업로드일은 `captured_at` 으로 쓰지 않는다. 제목·설명에 "Retour en archives", "Montage d'archives", "오늘" 류가 있으면 회고 편집물로 보고 `captured_at` 을 비운다. 공식 영화(예: "Official … Film")는 `year` 를 쓰되 캡션에 "대회 공식 영화"를 쓴다(PM 확인, 10절 D5).
3. 회고 몽타주를 "같은 날"로 올리지 않는다: 제품 정의서 6.1절.

결론: `display_mode` 가 어떤 조건에서 `embed`/`image`/`link_only` 인가.
- **비상업(PM 결정 2026-10-11)**: A는 파일 라이선스를 `license` 에 그대로 쓰고 `image` 로 직접 표시한다. B는 `status.embeddable=true` 이고 `regionRestriction` 이 서비스 사용 지역(캐나다)을 막지 않으면 `video_embed`. C는 CC BY-NC-SA 표기와 출처 표기를 붙여 `image` 로 쓸 수 있으나 큐레이션 대상이다. D는 약관의 "개인적 사용만" 해석(D1) 전에는 쓰지 않는다. LAC·BCA·PAA·토론토 포털·밴쿠버·BAnQ·글렌보를 직접 표시하는 경로는 만들 수 없다(자동 접근 불가, 일부는 연구용 한정). 6.2절에 따라 기술적으로 막힌 자료는 쓰지 않는다.
- **상업**: A는 PD, CC BY 2.0 만. B는 약관상 가능하나 광고 판단이 더 필요(V문서). C, D는 불가. LAC·PAA·BCA는 서면 허락.

## 6. PM이 실행할 확인 명령

### 6.0 PM이 할 일 (실행 순서)

1. C1~C4를 실행한다(키: `YOUTUBE_API_KEY`가 이미 있으면 그대로 쓴다). 사용량은 **검색 버킷 9회, 일반 버킷 약 9단위**다. 같은 날 다른 확인에 검색 버킷을 쓰지 않는지 먼저 본다.

3. 결과를 오케스트레이터에게 준다. data-researcher가 새 커밋으로 3.2절 표의 채널 ID와 카드의 확신도를 올린다(계획서 T10).

## 8. 위험

큰 것부터.
1. **자동 검색 가능한 캐나다 기록보관소가 없다**: LAC는 API 없음·확인 화면, 토론토는 robots 전체 금지, 몽레알은 60초 간격, 밴쿠버·BAnQ·캘거리는 봇 차단 [4][5][29][35][37][40][41]. 사진은 Commons의 일부 기관 사본에 의존하므로 "그날" 사진이 거의 비는 것이 정상이다(5절).
2. **캐나다 한정 영상**: Radio-Canada Archives 표본 2건 중 1건이 캐나다에서만 재생된다 [24]. 캐나다 밖(예: PM의 개발 환경)에서는 재생·확인이 안 될 수 있다. 서비스는 `contentDetails.regionRestriction` 을 읽어 요청 지역을 판단해야 한다.
3. **업로드일 ≠ 촬영일**: 표본 영상의 업로드일은 사건보다 26~50년 늦다(2010년 영상 2건은 17일·58일 뒤). 회고 몽타주를 "그날"로 표시하면 6.1절 위반이다. 4절 규칙이 필요하다.
4. **프랑스어 제목**: Radio-Canada 영상은 프랑스어라 영어 사건어 검색이 빗나간다(표본 제목 관찰). 사건어를 Wikidata 프랑스어 라벨 등으로 보강해야 한다(구현 S3b).
5. **YouTube 검색 버킷**: 채널 N개면 하루 새 날짜가 80/(3N)이다(3.2절). 채널을 늘릴수록 급감한다.
6. **Flickr 사본의 날짜 함정**: LAC 표본 6건 중 3건, 토론토 표본 6건 중 2건의 `DateTimeOriginal` 이 업로드일이다 [32]. 규칙이 없으면 1800년대 도판이 2004년 사진이 된다.
7. **라이선스 표기가 비표준**: `Attribution`(토론토 사본), LAC의 "no restrictions" 표기와 실제 권리 불일치(Commons 범주 안내는 커뮤니티 노트) [32][33]. `license` 는 원문 그대로 두고 확인 안 된 것은 "라이선스 확인 안 됨"으로 표시한다(제품 정의서 6.2절).
8. **NFB 임베드 조항**: "개인적 사용만, 상업 금지" [12]는 해석이 필요하다(10절 D1).
9. **몽레알 CC BY-NC-SA 4.0**: share-alike가 크롭·리사이즈에 걸리는지 해석이 필요하다(10절 D2).
10. **통신사 크레딧**: The Canadian Press가 `excluded-credits` 에 없다. CP 크레딧 형식은 미확인이다.
11. **약관 개정**: YouTube 개발자 정책과 쿼터 문서가 2026-10-15에 갱신되었다. 오늘 읽은 조항 내용은 V문서 T0c(2026-10-25)와 뜻이 같았다 [44][45].
12. **읽지 못한 공식 문서**: CBC, LAC 기록, 밴쿠버, BAnQ, 글렌보, Memorial DAI. 이 도구의 WebFetch User-Agent("Claude-User" 포함)가 일부 사이트에서 차단되었을 수 있다. B1~B8로 사람이 읽어야 한다.
13. **영상 페이지 HTML은 단서일 뿐**: 업로드일, `playableInEmbed`, `availableCountries` 는 영상 페이지의 공개 HTML에서 읽은 값이다. 공식 API 응답(6절 C3)으로 확인되기 전까지 구현 근거가 아니다.
