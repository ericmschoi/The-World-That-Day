## PM 미디어 결정 (2026-10-11)

- **사진과 영상은 링크로 처리하지 않는다. 결과 화면에서 바로 보이고 바로 재생된다.** 라이선스가 확인되지 않은 자료도 직접 보여 준다(PM 선택지 (c), 비상업). 원 출처가 핫링크·임베드를 기술적으로 막은 경우만 `link_only` 가 남는다.
- 영상: 화면에 보이면 **음소거로 자동 재생**, 누르면 소리, 벗어나면 멈춤. 움직임 줄이기·데이터 절약이면 자동 재생 안 함(M3-P8).
- **M3-P9 (b)**: 사용자가 넣은 **아무 날짜에서나** 그날 사건의 영상과 제공사 공식 임베드를 **자동으로 찾아** 보여 준다. 데모 날짜 큐레이션은 확인용 기준표로만 둔다. **영상이 없는 날짜는 사진만 나오는 것이 정상**이다(오류 아님). PM의 말: "데모 3개 날짜만 되는건 의미가 없어. 다 되는지 확인해야돼. 해당 날짜에 영상이 없으면 사진만 나와도 돼."
- 안전장치 (PM 확인):
  1. 미디어 파일을 우리 서버·저장소에 복사·재배포하지 않는다. 원 출처 주소(핫링크)나 공식 플레이어·공식 임베드로만. (M3-P10: 자유 라이선스 자료의 Git 밖 사본 #13 (a)는 허용)
  2. 모든 미디어에 출처, 라이선스(모르면 "라이선스 확인 안 됨"), 촬영 시점·정밀도. 6.1절·6.3절 그대로.
  3. 통신사·언론사 사진은 직접 가져다 쓰기(핫링크 포함) 금지. 제공사 **공식 퍼가기(임베드)** 로는 허용.
  4. 경로 우선순위: 자유 라이선스 → 임베드 허용 공식 채널·제공사 공식 임베드 → 그 밖 직접 표시.
  5. 출처별 차단 목록(설정값)으로 권리자 요청 시 바로 내린다.
  6. 공개 배포(#5)를 정할 때 다시 본다.
- 이 결정으로 바뀐 것: #4는 "바로 재생". #18은 `display_mode` 를 표시·재생 방식(`image` / `image_embed` / `video_file` / `video_embed` / `sdk` / `link_only`)으로 개정(M3a3). #9는 화면 표시를 막지 않는다(공개 배포 판단용).

4. **저작권 — PM이 위험을 알고 정함 (2026-10-11)**

5. **자동 검색의 정확도와 쿼터** — 엉뚱한 영상(이름만 같은 다른 사건, 기념·재현 영상)이 붙을 수 있고, YouTube Data API 쿼터가 하루 요청 수를 제한한다. 대응: 정확도 규칙과 기준선(확실하지 않으면 붙이지 않음), 표본 날짜 PM 품질 확인과 기준표, 차단 목록, 사건 3개 제한(M3-P12), 결과 캐시, 쿼터 상한 80%(넘으면 그 출처만 빠짐). `tragic` 사건·날에는 영상을 찾지 않는다.
